# GUM事例で残る改良課題

[現行の試算結果](workflow-results.md)と[操作方法](../../../docs/uncertainty-workflow-usage.md)を参照する。

- H.1：一次近似の点検はできるが、二次の分散の自動補正は未実装。
- H.2・H.4：同時観測表と派生列、入力と出力の共分散を扱える。表の対応関係や単位を作業者が確認する必要がある。
- H.3：回帰の平均応答への接続で、共分散と残差自由度を保持する。xに不確かさを持つ回帰や、新しい一観測の予測区間は対象外。
- H.5：原文の日平均からuを評価できるが、日内・日間分散の分析やF検定を行う機能は未実装。
- H.6：未提示の自由度は根拠をもって別途評価する必要がある。現在のサンプルのinfは仮定として明記。
- 任意の相関係数だけでは推定元の自由度は決まらない。共通の推定元が不明なときは、uまでを表示し自動方式のk・Uを未評価とする。

分布・kの自動選択、汎用ANOVA、分野別専用画面、DBは今回追加しない。改良前のサンプル・比較結果は保持しない。
