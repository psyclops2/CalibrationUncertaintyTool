# 入力元接続による再試算

| モデル | 今回の確認 |
|---|---|
| [H1](../projects/H1.cutp) | 一次評価u≈31.6583 nm。99%・自由度16へ切捨てでk≈2.92078を自動計算 |
| [H2手法1](../projects/H2_approach1.cutp) | 同時観測表の平均と共分散からR・X・Zを計算。sin/cosの解釈を修正し、三つとも評価可能 |
| [H2手法2](../projects/H2_approach2.cutp) | 表の派生列で各組のR・X・Zを計算後に平均。外部で派生列を作って転記する操作を解消 |
| [H3](../projects/H3.cutp) | 回帰予測を直接接続し、補正−0.1493768 K、u≈0.0041386 K、自由度9を保持。係数の手動転記を解消 |
| [H4手法1](../projects/H4_approach1.cutp) | 計数表から崩壊・背景補正した率を派生列で計算し、平均と共分散をモデルへ伝播 |
| [H4手法2](../projects/H4_approach2.cutp) | 同じ計数表からサイクル比を派生列で求め、その平均を使用 |
| [H5](../projects/H5.cutp) | 提示された日平均10個を測定表に保持して評価。u≈18.0533 µV、自由度9 |
| [H6](../projects/H6.cutp) | 評価済み統計量とType B参照式から、HRC指数64.0、u≈0.554226を再確認 |

H.2では出力間の共分散と相関も計算・保存し、必要時にレポートへ出力できる。回帰・測定表の元の数値を変更したときに結果が更新されること、全8モデルの保存・再読込後にuが一致することを確認した。

H.1の二次伝播、H.5のANOVA/F検定、H.6で提示されていない自由度の評価は今回も未対応。H.4の単位はBq/kgで表示し、補正計数率は同じmin単位で比を取る。単位の自動換算を追加した例ではない。

手入力の相関だけで自由度を評価できない旧モデルでは、uまでを表示し、自由度・自動方式のk・Uを未評価とする。相関付き係数を独立とみなして自由度を計算する方法は使わない。回帰の推定元へ接続することにより、その統計的な自由度を保持している。

再実行：

```powershell
.\venv\Scripts\python.exe examples/gum/scripts/verify_workflow.py
```
