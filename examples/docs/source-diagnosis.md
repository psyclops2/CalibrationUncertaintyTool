# 原典との差が発生する段階の確認

以前の「未確定」という記録から、さらに原典の入力・感度・寄与・合成の段階を調査した。

[診断スクリプト](../diagnose_sources.py)は原典から別に転記した入力と手で導いた感度式を使い、実行中のToolの入力値、標準不確かさ、感度係数、共分散、中心値、合成不確かさ、有効自由度を項ごとに比較する。保存された合成結果だけを検査する方法とは異なる。[実行記録](../source-diagnosis.json)を参照。

| 対象 | 差の発生箇所と根拠 |
|---|---|
| EA S2 | 原典の丸め済み寄与22.5、8.66、14.4、5.77、5.77 mgの二乗和は29.2436557 mgで、29.2 mgを再現する。未丸め入力からの29.2617498 mgとの差は、途中の寄与の丸めに発生する。 |
| EA S6 | 原典の掲載寄与の二乗和は0.0161892125。各寄与に最終表示桁の±1単位を許した範囲でも、合成値の上限は0.0162101913で、掲載合成値0.01623に±1単位を許した下限0.01622より小さい。通常の切上げ・切捨て・四捨五入の差では説明できない、原典の寄与列と合成欄の数値的不整合。Toolへ掲載寄与を直接入力しても0.0161892125となる。原入力からのToolの各感度・寄与は別の閉じた式と一致する。 |
| EA S7 | 分解能補正の行はu=0.0003 dB、感度1なのに寄与0.0019 dBと記載されている。掲載寄与をそのまま合成すると0.0222558 dBとなり、掲載合成値0.0223 dBを再現する。この行を0.0003へ直すと0.0221766 dB。原観測と仕様から未丸めで計算したToolの0.0222195 dBとの差には、他の途中値の丸めも含まれる。原典の寄与行の算術不整合を特定できるが、原著者の実際の計算ファイルを復元したという意味ではない。 |
| EA S13 | 観測列からの平均のu=0.146581 µmとゼロ点の0.25 µmを合成すると0.289803 µm。原典は途中値0.30 µmを採用する。この0.30 µmと、原典の温度小バジェット4項から求めた0.147949 µmなどをToolへ直接入力すると0.411387 µmで、掲載の0.411 µmを再現する。原式の一次計算との差は、途中値の採用と温度の高次寄与の有無に分離される。中心値も、原典表の平均49.99955 mmと正の補正0.000004 mmを使えば90.000254 mmとなり掲載値へ丸まる。元の観測列・本文の負の補正とは採用条件が異なる。 |
| GUM H.2 | 原典の5組から、Xの感度は約43.978098、−11181.858090、127.732170。各観測の偏差をこの感度で射影し、その二乗和を5×4で割ると分散0.0873685279901461 Ω²、u=0.295581677359 Ω。共分散行列を使うToolの経路とも一致する。表示された5組と一次伝播式に従えば0.296へ丸まり、掲載0.295とは一致しない。相関計算・微分・合成のTool側の各段階を照合したうえで、原典の手法1の掲載要約値との不整合へ局在できる。手法2は別の計算であり、厳密には同じ結果にならない。 |
| GUM H.4 | 原観測からの比は3.16661071388、中心値429.945822968 Bq/kg。原典掲載の丸めた比3.167を使うと429.998678199 Bq/kgとなり、掲載430.0を再現する。途中の比の丸めに発生する差。 |

EURAMETでは、掲載密度の表示桁だけから原典の未丸め中心値を一意に復元できない。したがって原典を再現する入力データとしての不足がある。一方、掲載密度をそのまま使った式(1)の閉じた計算とToolの全感度・共分散・合成を比較すれば、その入力に対するToolの演算経路を検証できる。この区別を維持し、原典の結果に合うよう密度を逆算して本番サンプルへ入力することはしない。

今回の照合対象である計算経路に、入力・感度・共分散・合成の数値的な不一致があればスクリプトは失敗する。対象外の式や条件までToolに問題がないという結論にはしない。
