# 原典とサンプルの計算結果の差

追跡調査：[差が発生する段階の確認](source-diagnosis.md)。以下の初回調査で未確定としたS2・S6・S7・S13・H.2・H.4について、途中値・感度・共分散まで調べた結果を記録している。

2026-11-21に、EA-4/02 M、GUM、EURAMETの24モデルを再点検した。保存・再読込の一致は、原典を正しく再現したことの検証にはならない。前回の確認はこの区別が不十分だった。

## Toolの計算処理の確認

[独立検算スクリプト](../audit_numerics.py)は、Toolの式解析・感度・Type A・参照式・共分散・自由度の計算関数を呼び出さない。`.cutp`の入力を読み、別の式評価処理とmpmathの60桁演算で次を確認する。

- 観測列から平均、平均の分散・共分散、プール評価、回帰予測を再計算する。
- 参照式からType Bの半値幅を再計算し、保存された除数で標準不確かさへ変換する。
- 数値微分から一次感度を求め、相関を含めて伝播する。自由度は統計的な入力元ごとにまとめて評価する。
- 指定したt分布の包含確率を密度関数の直接積分で確認する。手動・EA表・従来互換の係数と拡張不確かさも確認する。

24モデルの中心値・合成標準不確かさ・有効自由度・拡張不確かさは、独立計算と相対差2×10⁻¹⁰以内で一致した。t分布方式の包含確率の差は10⁻¹²未満だった。詳細は[検算記録](../numerical-audit.json)を参照。

これは入力済みモデルに対する一次計算の検証であり、原典の転記・モデル選択・未実装の高次伝播まで正しいことを保証しない。一般の式、全ての分布、全ての包含方式やMCを網羅した検証でもない。

## 修正した説明と検証方法

EURAMETの「表4に自由度1727」という以前の注記は、手元のv4.1原本では確認できなかったため削除した。「約95%」と「厳密な95%」の違いも明記した。これらはサンプル説明の誤り・不足であり、原典の誤りではない。

GUM生成処理の一律2.5%のu許容と、中心値に対する一律0.2%の許容を数値検証の根拠として使う処理を廃止した。原典との差はそのまま記録し、生成したモデルの正しさは独立検算で確認する。

再実行はリポジトリ直下から行う。

```powershell
.\venv\Scripts\python.exe examples/audit_numerics.py
```
