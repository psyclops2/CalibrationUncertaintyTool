# EA-4/02で残る改良課題

[現行モデルの採用条件](improvements.md)と[共通のGUI・評価機能の設計](../../../docs/uncertainty-workflow-design.md)を参照する。

- S4・S13：一次近似で落ちる項を検出できるが、一般的な二次伝播は未実装。MCは必要時に明示実行する。
- S5：同一モデルの段階計算は複数式で扱える。証明書の換算関数や、二段階で共有する誤差の条件が原文から定まる範囲を確認する必要がある。
- S7：dBを通常の線形な単位と同じ扱いにせず、量の定義を確認した単位検証が必要。
- S9〜S11：採用根拠付きのk指定を保持。非正規分布からkを自動選択する機能は追加していない。
- S12：kPa等の単位表記の補強は後続課題。数値分位点と掲載表の丸め値は区別する。
- 未提示の自由度や、原文の数値・記載の不整合を、Tool側の補正で隠さない。

プール標準偏差、評価済み統計量、回帰の入力元接続、同時観測表、出力共分散、任意の包含確率は共通機能で扱う。改良前のサンプル・レポートは削除済み。
