# EURAMET cg-19：画像付き事例

出典と利用条件は [共通のNOTICE](../NOTICE.md)を参照。原本PDFはローカル参照用であり、公開・配布対象には含めない。

EURAMET Calibration Guide No. 19 **v4.1 (12/2025)** の第7章を基にした、重量法による体積校正の2モデルです。原文の図や表を転載したものではなく、数値入力から独立に再計算するサンプルです。

原資料：[EURAMET公式PDF](https://www.euramet.org/Media/docs/Publications/calguides/I-CAL-GUI-019_Calibration_Guide_No._19_web.pdf)。取得した原本は `sources/euramet-cg19.pdf` に保存しています。

## モデルと添付図

式(1)の秤量差、浮力補正、20 °Cへの換算をそのまま式として入力しています。メニスカスと繰返しは加算補正項です。共通説明に重量法の計算手順図、点別説明にメニスカスの模式図を添付しました。どちらも本サンプル用に作図した説明図であり、EURAMET原図の転載ではありません。

画像と数値は `.cutp` 内に同梱しています。HTMLにも画像を内包しているため、プロジェクト・HTMLそれぞれ単独で移動できます。画像の参照は説明文中の `![キャプション](asset:画像ID)` です。

Type Bの入力は、参照値・参照式を使用します。評価済み標準不確かさは除数1の正規分布として扱い、熱膨張係数は中心値の±5%、メニスカスは±0.015 mLを矩形分布で評価します。ピクノメータのメニスカスと、両事例の蒸発は原文に従って無視しています。

Type Aは原文の平均の標準不確かさと自由度9を要約値として入力しています。原文にない観測列は生成していません。共分散を0とする原文の扱いを継承していますが、水密度の温度成分と容器温度の共通性は再構成していません。実務への転用時には相関の再検討が必要です。

## 計算結果と原文との差

包含係数は **95%両側t分位点・有効自由度を下側整数へ切捨て**として自動計算しています。

| 量 | フラスコ | ピクノメータ |
|---|---:|---:|
| V20 / mL | 999.608733407 | 100.016139883 |
| u(V20) / mL | 0.0168852120 | 0.000881979070 |
| νeff | 19.0436895 | 13.2948395 |
| k（95%） | 2.09302405 | 2.16036866 |
| U / mL | 0.0353411550 | 0.00190539994 |

原文の掲載結果への一致を目的に数値を調整していません。

[原典との不一致の調査](../docs/numerical-discrepancies.md)に、密度の精度・包含条件・独立検算の詳細を記載しています。

- **中心値**：原文は999.628 mL／100.014 mLですが、サンプルでは表の丸め済み密度を式(1)に代入しています。密度の表示精度が不足しており、原典の中心値を再現する入力条件になっていません。原文にあるTanaka式で水密度を再評価すると、空気密度0.0012 g/mLを据え置いた場合、999.622438 mL／100.014167 mLになります。フラスコについてはこれだけでは差を解消できず、原典が使った未丸め密度・補正条件を特定できていません。原典の計算ミスとは断定しません。
- **分銅密度の不確かさ**：本文は0.03 g/mL、表は0.0346 g/mL。本モデルは表を採用しています。
- **感度の符号**：フラスコの熱膨張係数に対する感度は、式(1)と温度19.11 °Cから正になります。表2の負符号は採用していません。
- **有効自由度**：ピクノメータの原文掲載値13に対し、再計算値は約13.295です。以前の説明にあった「表4の1727」は手元のv4.1原本では確認できず、誤った注記として削除しました。
- **包含係数**：原文は「約95%」、本モデルは厳密な95%を指定しており、条件が異なります。原文の2.15／2.21は、自由度19／13のt分布でそれぞれ約95.54%／95.43%に対応します。この差だけを原典やToolの計算ミスとは扱いません。
- **丸め**：表にある標準不確かさを使うため、途中式の未丸め値や本文の値を使った計算とは差が生じます。

## 再生成・検証

リポジトリ直下で実行します。

```powershell
.\venv\Scripts\python.exe examples/euramet19/scripts/build_samples.py
```

解析式から独立に求めた感度係数で中心値・合成標準不確かさ・有効自由度を検算し、保存・再読み込み後の結果一致と、Qtでの画像読込を検証します。詳細は `reports/verification.json` に保存します。モンテカルロは実行しません。

説明欄への画像追加は右上の **画像を挿入** ボタンを押します。**Ctrl+V**、または **右クリック → 画像ファイルを挿入** でも追加できます。キャプションと出典を入力できます。説明文中の画像記法を削除すれば、該当箇所の表示を外せます。
