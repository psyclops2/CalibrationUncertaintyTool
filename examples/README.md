# 計算サンプル

利用者指定の追加例：[1 V・5 V・10 Vの電圧比較](voltage_comparison/README.md)。以下の原典事例とは別のサンプルです。

参照値は全式・全校正点で同じ値を使うものに統一しています。Type Bの計算式には名前付き引数と取得方法を保存し、「参照式を設定」から対応を確認・編集できます。

現在の実装で再計算した24モデルです。Toolの「ファイル → 開く」で各`projects`フォルダの`.cutp`を読み込みます。計算結果は読み込んだ入力から再計算されます。HTMLは結果確認用のレポートです。

| 出典 | 収録範囲 | モデル数 | プロジェクトと説明 | 計算結果 |
|---|---|---:|---|---|
| EA-4/02 M:2022 rev03 | S2〜S7、S9〜S13の全11事例 | 14 | [EAサンプル](ea402/README.md) | [結果一覧](ea402/reports/index.html) |
| JCGM 100:2008（GUM） | 附属書Hの全6事例 | 8 | [GUMサンプル](gum/README.md) | [結果一覧](gum/reports/index.html) |
| EURAMET cg-19 v4.1 | 第7章のフラスコ、ピクノメータ | 2 | [画像付きサンプル](euramet19/README.md) | [フラスコ](euramet19/reports/flask.html)・[ピクノメータ](euramet19/reports/pycnometer.html) |

EAのS1とS8は導入章のため、計算モデルはありません。段階計算や異なる評価方法は別モデルで収録しています。全モデルに説明と独自作図を含め、画像は`.cutp`内に同梱しています。

文書情報には測定の概要、モデル式の意味、評価条件を記載しています。各量の説明には、量の意味と不確かさの評価方法を記載しています。EA・GUMの図は測定と評価の流れ、EURAMETの図は重量法とメニスカスの説明です。

保存・再読込後の計算結果の一致を確認しています。EAでは直接式の数値微分、GUMでは原文の掲載結果との比較や入力元の変更、EURAMETでは独立な解析式と画像読込も検証します。

原文を完全に再現できない部分は、各プロジェクトの説明と各フォルダの制約メモに記録しています。二次伝播、ANOVA、原文にない自由度などを補って再現したものではありません。MCは自動実行しません。

[原典との不一致の調査](docs/numerical-discrepancies.md)では、入力・評価方法の違い、一次近似で不足する項、原典内の不整合、未確定の差を分けて記載しています。[独立検算の記録](numerical-audit.json)と合わせて参照してください。

## 再生成

リポジトリ直下で実行します。各フォルダのサンプルとレポートを上書きするため、編集して使う場合は別の場所へ保存してください。

```powershell
.\venv\Scripts\python.exe examples/rebuild.py
```

既存の成果物の保存形式・画像・リンクだけを確認する場合：

```powershell
.\venv\Scripts\python.exe examples/rebuild.py --check-only
```

出典と利用条件は[NOTICE](NOTICE.md)を参照してください。原資料のPDFは配布対象に含めていません。
