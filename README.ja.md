# CAlibration uncertainty Tool

測定モデルを検討し、不確かさバジェットを作成するデスクトップアプリです。モデル式から感度係数を求め、合成標準不確かさ、有効自由度、包含係数、拡張不確かさを計算します。同じモデルで複数の校正点を扱えます。

Type A・Type Bの評価、回帰や同時観測表からの入力、相関を含む一次の不確かさ伝播、モンテカルロシミュレーションに対応しています。プロジェクトは画像を含めて保存でき、計算条件と結果をHTMLレポートへ出力できます。

## 動作環境と起動

Python 3.15系を使用します。確認環境はPython 3.15.2です。実行に必要なライブラリはPySide6、NumPy、SymPy、mpmath、Python-Markdownで、[requirements.txt](requirements.txt)に記載しています。

Windowsでは、プロジェクトのフォルダで次の順に実行します。

```powershell
.\setup.bat
.\run.bat
```

`setup.bat`は仮想環境を作成して依存ライブラリをインストールします。プロジェクト内の`.python\3.15.2\python.exe`がある場合はそれを使い、なければPATH上のPython 3.15を使います。別のPython系列ではセットアップを中止します。

通常は`run.bat`で起動します。実行すると翻訳ファイルを生成し、アプリを起動します。表示言語は「ツール → 設定」で日本語・英語を選択できます。英語画面のメニュー名は「Tools → Settings」です。一部のエラー本文には日本語が残っています。

コマンドで環境を作成して起動する場合は、Python 3.15を使い、プロジェクトのフォルダで実行します。

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe -m src.i18n.generate_translations
.\venv\Scripts\python.exe -m src
```

## 基本的な操作

1. 「文書情報」で文書番号、文書名、バージョン情報、説明文を入力します。改訂履歴は、版・改訂内容・作成者・照査者・承認者・改訂日の表に入力します。行の追加・削除もできます。
2. 「モデル式」で計算式を入力します。左辺を結果の量、右辺を入力の量として扱います。複数の式を使い、中間結果を別の式から参照することもできます。
3. 「校正点」で点を追加し、名前と順序を設定します。
4. 「変数管理」で量と校正点を選び、単位、説明、不確かさの種類、値を入力します。説明欄には画像も挿入できます。
5. 「不確かさ計算」で対象の結果と校正点を選び、バジェットと包含方法を確認します。「全校正点の結果一覧」では全点の状態を確認し、行をダブルクリックして詳細へ移動できます。
6. プロジェクトを保存します。配布・印刷用の計算内容は「レポート」で生成し、HTMLとして保存します。

回帰や測定表を使うときは、評価元のデータを用意してから変数管理の「入力元」へ接続します。操作の詳細は[回帰・測定表を入力元に使う](docs/uncertainty-workflow-usage.md)を参照してください。

## モデル式の入力

四則演算、括弧、べき乗、数学関数を使用できます。べき乗は`^`または`**`で入力します。たとえば`x^(-2)`は負の指数、`x^(n+1)`は式を指数にしたべき乗です。複数の式は改行・セミコロン・カンマで区切れます。関数の引数内のカンマは、式の区切りとして扱いません。

量名はGUM Workbench方式で表示します。`\rho\`などのコードをギリシア文字として表示し、`_`ごとに下付きの開始・終了を切り替えます。`x_a_b`ではaが下付き、bが通常位置になります。変数名の大文字・小文字は区別します。

入力欄の下にある「文字を挿入」「数式を挿入」から、文字や対応関数を選べます。関数の挿入後は引数部分が選択され、そのまま置き換えられます。三角関数の角度はラジアンです。

左辺の結果は直接入力せず、右辺から計算します。変数リストの順序はドラッグ操作で変更できます。コードとUnicode文字の扱い、べき乗の優先順位などは[モデル式の記法](docs/model-equation-notation.md)にまとめています。

## 量の値と不確かさ

変数管理では、量に共通する単位・説明と、校正点ごとの値・説明を分けて入力します。

| 種類 | 入力・評価の方法 |
|---|---|
| Type A | 観測列からの評価、プール標準偏差の使用、評価済み統計量の入力 |
| Type B | 中心値、不確かさの入力幅、分布、除数、自由度 |
| 固定値 | 不確かさを持たせない中心値 |
| 計算結果 | モデル式から計算。値の直接入力はしません |

Type Aの通常の評価では、観測列から平均と平均の標準不確かさを求め、自由度を観測数から1を引いた値とします。「評価方法」ではプール標準偏差や評価済み統計量へ切り替えられます。要約値を使う場合も、その自由度と評価根拠を入力します。

Type Bでは、入力幅を除数で割って標準不確かさを求めます。画面の「半値幅」欄には、矩形・三角・U字分布では半値幅を、正規分布では指定した包含係数に対応する不確かさの幅を入力します。正規分布の除数は採用した値に合わせて設定します。

| 分布 | 入力幅をaとした標準不確かさ |
|---|---|
| 正規 | `a / k`。除数にkを指定 |
| 矩形 | `a / sqrt(3)` |
| 三角 | `a / sqrt(6)` |
| U字 | `a / sqrt(2)` |

### 参照値とType B参照式

「ツール → 参照値」で、仕様係数などを名前・値・単位とともに登録できます。変数管理でType Bの「参照式を設定」を押すと、選択中の量の式を編集できます。

新規作成では「計算式 → 入力の対応付け → 計算結果の確認」の順に設定します。式には任意の引数名を使い、各引数へ全点共通の数値、点ごとの数値、登録済みの参照値、量の各点の中心値を対応付けます。手入力値は各式の引数として管理し、共用する参照値の一覧には表示しません。取得方法を変更して使わなくなった手入力値は、他で参照されていなければ削除します。分布と除数は変数管理の設定を使います。

たとえば、100 ppm of setting + 1 mVの仕様では、設定値に比例する項と1 mVの定数項から入力幅を求めます。of rangeの仕様を扱う場合は、レンジ値を参照します。各項の単位は入力時にそろえます。数値の単位換算は自動ではありません。

登録後は確認画面から、式や入力の対応付けを直接編集できます。既存の点別式は保持し、「点ごとの別式を編集」から変更できます。「直接入力へ戻す」を押すと、その量の全点の参照式を解除し、最後に評価した幅を保持します。入力エラーがある場合は適用せず、理由を表示します。詳しくは[設定手順](docs/reference-formula-usage.md)を参照してください。

参照値は物理定数など、プロジェクト内の全式・全校正点で同じ値を使うためのものです。参照値同士の式も利用できますが、測定値や点別値には依存できません。点ごとに変わる値は、対象量の引数設定で入力します。旧ファイルの点別参照は読取専用で保持し、新規の参照先候補には表示しません。

### 回帰・測定表を入力元に使う

Type Aの「入力元」には、直接入力、回帰の平均応答、測定表の列の平均を選べます。元データを変更すると、接続した量の評価値も更新します。

回帰からの接続は、xの不確かさを無視できる直線回帰の平均応答を対象とします。評価するxには固定の数値・式、または固定量の現在点を指定します。接続には3組以上のデータが必要で、xに不確かさがある回帰や、不確かさを持つ量をxに指定する接続は受け付けません。

同時観測の測定表では、同じ行を一組の観測として扱います。元データの列に加え、行ごとに式を評価する派生列を作れます。欠測を含む観測組は行全体を除外します。同じ表の列の平均どうしや、同じ回帰から得た評価値どうしの共分散を計算に反映します。

接続を解除して直接入力へ戻すと、接続前の入力を復元します。その時点の評価値を統計量として固定する方法も選べます。入力元が削除された場合や列が見つからない場合は理由を表示し、以前の値を最新の評価値として使いません。

## 不確かさの計算と包含方法

モデル式の偏微分から感度係数を求め、入力の標準不確かさと共分散を使って一次の不確かさ伝播を計算します。相関係数表は入力の量を対象とし、上三角のセルを編集します。対角は1、下三角は上三角と同じ値です。相関係数は−1から1の範囲で指定し、成立しない行列は自動補正せず、計算を止めて理由を表示します。

独立な入力の有効自由度には、寄与不確かさを4乗するWelch–Satterthwaite近似を使います。寄与不確かさが負の場合も、4乗の項に含めます。回帰や同時観測表からの入力では、推定元ごとの共分散と自由度を使います。

「包含係数の評価方法…」で、結果・校正点ごとに次の方法を選びます。拡張不確かさは、合成標準不確かさに包含係数kを掛けた値です。

| 方法 | 動作 |
|---|---|
| 従来互換 | 有効自由度10以上はk=2。それ未満は設定ファイルのt分布表を使用 |
| 設定ファイルのt分布表 | `config.ini`の`[TValues]`を使用 |
| EA-4/02表E.1 | 95.45%の掲載値を使用。有効自由度を切り捨て、表にない有限自由度には下側の掲載値を使用 |
| 包含係数を指定 | kと採用根拠を入力 |
| 包含確率から計算 | 指定確率と有効自由度からt分位点を計算。自由度の切捨ては選択可能 |

任意の手入力相関を設定した場合など、有効自由度を評価できない組合せがあります。その場合も合成標準不確かさは表示しますが、自動方式のk・拡張不確かさは未評価にします。

「一次近似を点検」は、一次感度が0でも二次の寄与があり得る特定の項を調べます。標準不確かさの補正やモンテカルロの実行は行いません。複数の結果を持つモデルでは「結果どうしの相関…」で出力間の共分散・相関を確認し、レポートへ含めることもできます。

### モンテカルロシミュレーション

モンテカルロは「モンテカルロ」タブの実行ボタンで開始します。タブを開くだけでは実行しません。正規・矩形・三角・U字分布に対応し、ヒストグラムと95%区間を表示します。接続した回帰・測定表の統計量には、多変量正規近似を使用します。

「詳細な試行条件」から乱数シードを指定できます。「試行結果を保存…」では、試行数、シード、NumPyの版、モデルのスナップショット、MCの統計量、一次計算の標準不確かさをJSONへ保存します。MCで生成した標本列は保存しません。試行記録はプロジェクトとは別のファイルです。

モデルや入力値を変更すると、以前の試行結果を無効にします。更新後の結果を得るには再実行します。

## その他の機能

| 画面・操作 | 内容 |
|---|---|
| 回帰モデル | モデルの追加・複製・削除、x・u(x)・yの入力、CSV貼り付け取込、直線の係数と残差の評価、y0からの逆推定 |
| 偏微分 | 中間式を展開したうえで、元の入力に対する偏微分式を表示 |
| 単位整合検証 | 量の単位と式の次元を解析し、OK・WARN・ERRORを表示 |
| 一括入力モード | Type Bと固定値を校正点ごとの表で更新。空の数値セルは既存値を保持し、不正な入力は適用しません |

単位整合検証は次元の確認です。単位を変更しても数値は換算されません。一括入力では分布や値の変更に伴い、Type Bの除数・自由度・標準不確かさを更新する場合があります。

## 説明文・画像・レポート

文書情報の説明文と、量の共通説明・点別説明にはMarkdownを使えます。量の説明欄の「画像を挿入」からPNG・JPEGを選択できます。Ctrl+Vでの画像貼り付けや、右クリックからの挿入にも対応し、キャプション・出典を入力できます。

取り込んだ画像はプロジェクトに含めて保存します。元の画像ファイルを移動しても参照は切れません。同一の画像本体は重複保存しません。

「レポート」では、選択した結果について全校正点の入力・バジェット・計算結果をHTMLに出力します。量の説明に添付した画像もHTMLへ埋め込むため、HTMLファイルだけで閲覧できます。表示の調整には`css/default.css`と`css/custom.css`を使います。

## 保存形式と復旧

標準保存形式は`.cutp`です。ZIP内に`manifest.json`、`project.json`、画像を格納します。`.zip`と単体の`.json`も保存・読み込みでき、既存のJSONプロジェクトも開けます。JSONで画像を保存する場合は、画像データをBase64で含めます。ファイル容量は、ZIPでは展開後の合計、JSONではファイル全体で256 MiBまでです。

保存対象は、文書情報、モデル式、校正点、各量の入力と評価条件、相関、参照値・参照式、回帰モデル、測定表、画像です。計算結果一覧そのものは保存せず、モデルと入力値から再計算して表示します。

未保存の変更があるときはタイトルに`*`を表示し、新規作成・読み込み・終了時に保存を確認します。通常の保存では一時ファイルへの書き込み後に保存先を置き換えます。読み込みではデータ形式を検証し、画面への反映に失敗した場合は元の作業内容へ戻します。

30秒ごとに変更を確認し、前回の復旧用保存から内容が変わった場合だけ、未保存データを`logs/recovery-*.cutp`へ保存します。異常終了後の次回起動時に復旧を選べます。従来のJSON復旧ファイルも対象です。通常終了や保存後は復旧用データを削除します。

## 設定

「ツール → 設定」で、計算精度、丸め、有効数字、言語などを変更できます。設定の保存先はアプリのフォルダ直下の[config.ini](config.ini)です。計算精度の設定はDecimalを使う処理に適用します。回帰やモンテカルロなどには浮動小数点計算も使用しています。

| 設定項目 | 保存先 |
|---|---|
| Decimalの計算精度 | `[Calculation]` |
| 不確かさの表示有効数字・丸め方式 | `[UncertaintyRounding]` |
| 日本語・英語、システムロケールの使用 | `[Language]` |
| 分布ごとの除数 | `[Distribution]` |
| 包含係数のt分布表 | `[TValues]` |

丸め方式は、切上げの`round_up`と、切捨てによる相対差が5%以内かを判定する`5_percent`です。包含係数はプロジェクト側の評価方法と設定ファイルの両方に関係するため、使用する方式も確認してください。
