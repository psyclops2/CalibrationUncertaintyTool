# モデル式の量名と数式表示

参照：[GUM Workbench User Manual（公式ダウンロード案内）](https://metrodata.de/download_en.html)、§6.2.2、§6.4、§6.5.4、Appendix D（冊子p.25、31、33、35、147／PDF p.33、39、41、43、155）。ギリシア文字のコードと下付きの切替方法を参考にしています。マニュアルの全機能を実装したものではありません。原本PDFはローカル参照用とし、配布対象には含めません。

## ギリシア文字

両端をバックスラッシュで囲んだコードを入力できます。

```text
V_20 = m / (\rho\_W - \rho\_A) * (1 - \gamma\*(t - 20))
```

入力欄には入力したコードを残し、数式プレビュー・偏微分・レポートではρ、γなどの文字として表示します。量名は内部ではUnicode文字に統一するため、`\rho\_W`と`ρ_W`は同じ量です。保存後もモデル式入力欄のコード表記を保持します。

入力欄下の「文字を挿入」「数式を挿入」は、どちらもボタンから一覧を開き、項目を選んでカーソル位置へ挿入します。文字は小文字・大文字・異体字から選べます。関数の挿入後は引数部分が選択されるため、そのまま置き換えられます。コードは英語名で、大文字は先頭を大文字にします（`\gamma\`→γ、`\Gamma\`→Γ）。

マニュアルの対応に従い、`\theta\`→ϑ、`\theta1\`→θ、`\phi\`→ϕ、`\phi1\`→φ、`\sigma\`→σ、`\sigma1\`→ςです。これらの異体字は別の量として保持します。`\mu\`→µです。

英単語の`rho`や`alpha`を自動でギリシア文字へ置換しません。従来からの`pi`は円周率の定数です。`\pi\`や`π`は量名となるため区別してください。未登録のバックスラッシュコードは構文エラーになります。Appendix Dの非ギリシア特殊文字コード（`\us\`など）は今回の対応範囲に含みません。

## アンダースコア

量名は **GUM Workbench方式に固定** しています。`_`ごとに下付きを開始・終了します。

| 入力 | 表示の意味 |
|---|---|
| `x_ref` | refを下付き |
| `x_ref_` | refを下付きにした後、通常位置へ戻る |
| `x_a_b` | aを下付き、bを通常位置で表示 |
| `\rho\_W` | ρのWを下付き |

既存のJSON／CUTPに保存された従来表示の指定も、読み込み時にはGUM方式として表示します。変数名のキーや数値、参照先は変更しません。例えば、既存の`V_ref_stability`はrefだけが下付き、stabilityが通常位置になります。`x_ref`と`x_ref_`は表示が同じでも別の量です。

## べき乗

モデル式の`^`はべき乗演算子です。量名の一部や装飾用の上付き記号としては使いません。従来互換として`**`も同じ演算として受け付けます。

```text
Y = x^2
Y = x**2
Y = x^(-2)
Y = x^(n+1)
```

プレビュー・偏微分・レポートでは指数を上付きにします。計算の優先順位はべき乗、乗除、加減の順で、べき乗が連続した場合は右から評価します。

- `2^3^2 = 2^(3^2) = 512`
- `-2^2 = -(2^2) = -4`
- `(-2)^2 = 4`
