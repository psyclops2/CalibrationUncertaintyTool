# UI翻訳の更新

翻訳の修正元は `src/i18n/translations_ja.py` と `src/i18n/translations_en.py` です。追加したモデル検討・画像・改訂履歴の共通文言は `src/i18n/workflow_translations.py` にまとめ、`WorkflowUI`コンテキストで両辞書へ取り込みます。日本語の固定文言を原文キー、英語を訳文としています。

`.ts`と`.qm`は生成物です。これらだけを修正すると、`run.bat`が起動時に再生成した際に消えます。

```powershell
.\venv\Scripts\python.exe -m src.i18n.generate_translations
.\venv\Scripts\python.exe -m pytest tests/test_workflow_translation.py -q
```

共通文言を追加するときは `tr_ui('固定の原文')` を使い、翻訳辞書にも追加します。量名・モデル式・単位・利用者の説明・キャプションなどの入力データには翻訳関数を適用しません。動的文言は固定部分を翻訳し、値を後から挿入します。`{0}`などのプレースホルダと書式指定は原文と訳文で一致させます。

画面を開いたまま切り替える操作には、`retranslate_ui`や`LanguageChange`イベントで対応します。表示更新でコンボボックスの中身を作り直す場合は、シグナルをブロックし、モデルへの書込みを発生させないようにします。通常の操作で言語変更と同時に開かないモーダルダイアログは、生成時に現在の翻訳を読みます。

テストでは、辞書の文言・プレースホルダを検査し、一時ディレクトリに翻訳ファイルを再生成してから英語→日本語→英語へ切り替えます。操作ボタン・関数メニュー・改訂履歴・画像・評価設定の表示と、保存データの不変性を確認します。

旧実装のログ文字列や計算エラー本文には別途整理が必要な箇所があります。本テストの対象は追加したUIと共通文言であり、アプリ内の全メッセージの翻訳完了を保証するものではありません。
