# Type Bの入力幅を計算式から求める

変数管理でType Bの量を選び、「参照式を設定」を押します。矩形・三角・U字分布では半値幅、正規分布では除数で割る前の拡張不確かさを計算します。分布と除数は変数管理の設定を使います。

## 新しい式を設定する

1. 「計算式」で式を書きます。例えば `a * abs(reading) * 1e-6 + b * range * 1e-6` と入力します。aとbへppm単位の数値を渡す例です。引数の名前は自由で、係数を式へ直接書くこともできます。
2. 「次へ」で、式に現れる各引数の取得方法を指定します。全点共通の数値、校正点ごとの数値、登録済みの参照値、量の各点の中心値から選びます。点別の数値は点名に対応する欄へ入力します。
3. 「次へ」で、各点の採用値、計算した入力幅、標準不確かさを確認します。行を選ぶと、実際の値を代入した式を表示します。「適用」で反映し、「キャンセル」で変更を取り消します。

readingやrangeは特別な名前ではありません。公称値を使うか観測平均を使うかも、入力の対応付けで指定します。校正点名から数値を自動取得することはありません。数値の単位は自動換算しないため、各項の単位をそろえて入力してください。

レンジと仕様係数を点別の数値として設定した場合、一方を変えても他方は自動変更しません。

## 登録した式を変更する

登録済みの式は計算結果の確認画面から開きます。「式を変更」「入力の対応を変更」で、変更する部分へ直接移動できます。式に残っている引数の対応は保持します。追加した引数には取得方法を指定してください。

「直接入力へ戻す」は、その量の全点の参照式を解除し、最後に評価した幅を直接入力値として保持します。編集中の式を適用する操作とは別です。

## 既存の式・参照値

従来の実参照入りの式も読み込めます。名前付き引数の情報がない式では、参照をinput_1などの引数名で表示し、取得元を保持します。既存の点別式は基本式より優先します。「点ごとの別式を編集」で点を選び、基本式と同じ設定画面で編集します。外側の画面をキャンセルすれば本体には反映されません。「この点を基本式に戻す」で別式を解除できます。

複数の式で共用する値の登録・編集は「ツール → 参照値」から行います。各式の手入力値はこの一覧へ並べず、対象量の「参照式を設定」で編集します。使わなくなった手入力値は、他の式や参照値などから使われていなければ削除します。

旧「計算式＋計算」欄は廃止しました。旧ファイルの手動計算式は、新しい設定画面へ取り込んで確認できます。「適用」するまでは保存済みの幅を変更せず、適用後は旧欄のデータを除きます。内部IDを入力する必要はありません。

参照値は物理定数など、プロジェクト内の全式・全校正点で同じ値を使うためのものです。参照値同士の式も利用できますが、測定値や点別値には依存できません。点ごとに変わる値は、対象量の引数設定で入力します。旧ファイルの点別参照は読取専用で保持し、新規の参照先候補には表示しません。
