# 回帰・測定表を入力元に使う

変数管理で量と校正点を選び、Type Aの「入力元：直接入力…」を開く。既存の観測列や評価済み統計量の直接入力は、そのまま利用できる。

## 回帰予測の接続

1. 回帰タブに、x・yのデータと単位を登録する。
2. 変数管理で対象量をType Aにし、「入力元：直接入力…」から「回帰の平均応答」を選ぶ。
3. 回帰モデルと評価するxを指定し、「評価値を確認」で中心値・u・自由度・適用範囲を確認する。
4. OKで適用する。以後、元の回帰データや参照した固定量を変更すると、評価値を再計算する。

評価するxには数値・式、または固定量の現在点を指定できる。回帰がx=t−20°Cで定義されている場合、t=30°Cに対応するxは10 Kである。式の定義と単位をそろえて入力する。数値の単位換算は自動ではない。

対応範囲は、xの不確かさを無視できる線形最小二乗回帰の平均応答。新しい一観測の予測区間ではない。xに不確かさを持つ回帰や、不確かさを持つ量をxとして使う接続は、理由を表示して受け付けない。

「回帰タブでデータを編集…」から移動すると、回帰タブに元の量・校正点へ戻るボタンが表示される。戻ると入力元設定の編集中のxなどを復元する。この移動だけで接続設定は確定しない。

同じ回帰から得た複数の予測値には、共通の係数から計算した共分散を使う。係数や相関を手で転記する必要はない。既存の相関表で同じ組に異なる相関を手入力すると、競合として表示する。

## 同時観測と行ごとの計算

入力元で「測定表の列の平均」を選び、表を作成するか、既存の表と列を選ぶ。CSVは先頭行を列名としたUTF-8形式で取り込める。列名には重複しない量名を使う。

表の上側で列名・単位・派生列の式を設定し、下側で観測組を入力する。派生列の式を空欄にした列へ元の数値を入力する。たとえば電圧・電流・位相の列から、`voltage/current*cos(phase)`を派生列として計算できる。

同じ行が同じ観測組である。欠測のある組は行全体を除外する。列ごとに異なる観測を無言で使うことはない。「評価を確認」で使用した観測組数、平均、uを表示し、派生列の各行の値も確認できる。派生列の計算結果は直接編集しない。

元の列の平均をモデルへ渡す方法と、派生列を計算してから平均する方法を、使用する列で選び分ける。同じ表から使う列どうしの共分散を保持する。表を変更すると、それに接続した量を更新する。

派生列の式に使う数値は、入力した単位に合わせる。単位を変えただけで数値や係数は換算されない。ANOVAや群間差の検定は、この測定表では実行しない。

## 接続の解除

入力元を「直接入力」に戻すと、接続前に保存した直接入力を復元する。「接続中の評価値を統計量として固定」を選んだ場合は、その時点の評価値をType Aの評価済み統計量として保持し、評価元と固定時点を記録する。

取り消しでは元の入力を変えない。入力元が削除された場合や列が見つからない場合は、理由を表示して未評価とし、以前の評価値を最新結果として使わない。

## 包含条件と出力間の相関

不確かさ計算の「包含係数の評価方法…」で、「包含確率から計算」を選ぶ。95%、95.45%、99%などを指定できる。必要なら有効自由度を下側の整数へ切り捨てる。

EA表の掲載値を使う方式と、t分位点を数値計算する方式は別に保持する。たとえば自由度10・95.45%の数値計算はk≈2.28368、EA表の掲載値は2.28となる。既存ファイルの方式は自動変更しない。

任意の手入力相関だけでは推定元が分からず、自由度を評価できない場合がある。この場合もuを表示し、自動方式のk・Uは未評価とする。回帰や同時観測表のように推定元が明らかな組は、その共分散と自由度をまとめて評価する。

複数出力のモデルでは「結果どうしの相関…」を開ける。現在の校正点の共分散・相関行列を確認し、必要ならレポートへ含める。相関のあるバジェットの寄与率は、交差項を両方の量へ半分ずつ割り当てた値で、負になる場合がある。

## 必要時のMC試行

MCは実行ボタンを押したときに計算する。タブを開くだけでは実行しない。「詳細な試行条件」から乱数シードを指定でき、空欄では自動生成したシードを結果に表示する。

「試行結果を保存…」で、試行数、シード、NumPyの版、モデルのスナップショット、MCの標準偏差・等裾95%区間、一次計算のuをJSONへ保存する。サンプル列そのものは保存しない。試行記録はモデルJSONとは区別する。

接続した統計量は多変量正規近似でサンプリングする。MCの実行だけでこの仮定や包含区間の妥当性を検証したことにはならない。モデル・回帰・測定表・入力値の変更後は、以前の試行結果を無効にし、再実行を必要とする。
