# 不確かさ評価機能と入力の流れ

この文書は既存タブへ評価機能を追加した際の設計記録。追加の検討は[Type B参照式の設定手順の修正案](model-workspace-design.md)を参照。タブ全体の再編案は撤回し、既存タブ構成を維持する。

2026-11-21。EA-4/02とGUMの試算から整理した機能を、既存GUIへ組み込むための設計。ユーザーの「GUIを複雑にしすぎず、作業者の入力の流れを考慮する」という指示を反映する。

同日、実装順序1〜4の数学関数、回帰接続、包含確率、同時観測表・出力共分散を実装した。MCの明示実行・試行条件の保存も追加した。[操作方法](uncertainty-workflow-usage.md)と[GUMでの確認](../examples/gum/docs/workflow-results.md)を参照。単位接頭辞の補強などの後続課題、本文に記載した適用範囲外の機能は未実装。

## 作業の順序と画面の役割

基本の作業順序を、モデル式、校正点、入力値の評価、結果確認、レポートとする。画面間は自由に移動でき、試算中の式や値の変更も継続できる。手順を固定するウィザードは追加しない。

```mermaid
flowchart LR
    A[モデル式を入力] --> B[校正点を設定]
    B --> C[量を選んで値・評価方法を設定]
    C --> D[バジェットと結果を確認]
    D --> E[レポートを保存]
    D --> C
    D --> A
```

| 既存画面 | 作業者が行うこと | 必要なときに開く設定 |
|---|---|---|
| モデル式 | 式を記述し、入力量と出力量を確認する | 使用可能な数学関数の説明 |
| 回帰 | 元データを入力し、回帰の適合と適用範囲を確認する | 残差・係数の共分散などの詳細 |
| 校正点設定 | 使用する点を登録する | 現在の点管理機能を継続 |
| 変数管理 | 量と校正点を選び、入力元と評価方法を設定する | 回帰との接続、測定表、既存の参照式 |
| 不確かさ計算 | 中心値、u、自由度、包含条件、Uを確認する | 包含条件、出力量間の相関、一次近似の点検 |
| モンテカルロ | 必要なモデルで明示的に試行を実行する | 試行条件と一次計算との差の確認 |
| レポート | 採用した条件と結果を保存する | 条件・未評価項目も出力 |

新しい機能のためのトップレベルのタブは追加しない。既存タブの全面的な並べ替えも初期実装の対象にしない。回帰などの補助画面へ移動して戻る際は、量・校正点・入力途中の内容・スクロール位置を保持する。

## 変数管理での入力

変数管理は、現在の「校正点と量を選ぶ→右側で編集する」配置を維持する。入力元と不確かさの評価方法は別の情報として扱う。回帰をType A・Type Bに並ぶ新しい分類にはしない。

通常表示には入力元の要約を1行置く。直接入力では従来のA・B・固定値のフォームを使う。回帰や測定表を接続した量では、取得元の要約と計算済みの中心値・u・自由度を表示し、手で転記しない。

| 表示例 | 作業者の操作 |
|---|---|
| 入力元：直接入力　［変更…］ | 既存の観測列、評価済み統計量、Type Bの幅などを入力する |
| 入力元：回帰「温度計補正」／x=10 K　［変更…］ | 接続先または評価するxを変更する |
| 入力元：測定表「電気測定」／電圧列の平均　［変更…］ | 使用する表・列・評価方法を変更する |

この表は配置と表示文言の仕様であり、実装済みの画面画像ではない。入力元の選択肢は「変更…」の中に置く。回帰や測定表を使わない量に、その設定項目を並べない。

入力元を切り替えるダイアログでは、量名、校正点、適用範囲を見出しに表示する。適用前に中心値・u・自由度と単位をプレビューする。取り消した場合は元の入力を保持する。他の校正点へ無言で一括適用しない。

計算元がある値は読み取り専用にする。直接入力へ戻す場合は、接続を解除する操作と、現在の評価値を固定して引き継ぐ操作を区別する。固定した値には評価元と固定時点を記録し、自動更新される値と見分けられるようにする。

既存のType B参照式は、仕様から半値幅を求める入力として継続する。回帰の予測値の接続と、Type Bの半値幅の参照を同じ設定欄に混在させない。

## 回帰から予測値を使う操作

作業者は回帰タブにデータを入力し、変数管理の対象量で「入力元を変更→回帰」を選択する。そこで回帰モデルと評価するxを選ぶ。選択した回帰を編集するための移動操作も、この設定から利用できるようにする。

初期実装は既存の線形最小二乗回帰の平均応答を対象とする。GUM H.3の「補正曲線の推定値とその標準不確かさ」を扱う。新しい1回の観測に対する予測区間は別の評価であり、この機能へ暗黙に含めない。

| 接続設定の項目 | 内容 |
|---|---|
| 使用する回帰 | 登録済みの回帰モデルを名前で選択。内部では安定したIDで保持 |
| 評価するx | 固定数値、または既存の固定値参照・式から指定 |
| xとyの単位・定義 | 回帰側の定義を表示。温度差などの変換を無言で挿入しない |
| プレビュー | 推定値、標準不確かさ、自由度、回帰データ範囲 |
| 範囲外の場合 | 外挿であることを表示し、採用記録へ残す |

たとえば回帰のxが「t−20°C」で定義されている場合、t=30°Cに対する入力はx=10 Kとなる。この対応を画面で確認できるようにし、入力された30を内部で10へ自動変更しない。

初期実装では、評価するxの不確かさが無視できるケースまでを対象とする。不確かさを持つ量をxに指定したときは、その不確かさを取り落とさず、未対応の条件として理由を表示する。xの不確かさと回帰の不確かさを併せて伝播する機能は、依存関係を扱う計算を整えた後に追加する。

回帰の係数・共分散・自由度を個別に作業者へ再入力させない。GUM H.3で、回帰側の自由度9がモデル側でも保持されることを初期実装の受入条件とする。

## 推定元と依存関係の保持

内部では、中心値・u・自由度に加え、推定元のIDと共分散の情報を保持する。たとえば同じ回帰を異なるxで使った二つの予測値には相関がある。単一予測のuを独立したType A入力として複製すると、その関係を失う。

したがって、回帰の予測値は元の係数とその共分散へ接続する。同じ回帰を複数の量で使った場合も、共通する係数を同じ推定元として計算する。複数式で共通入力を展開する現在の機能と整合させる。

相関係数だけから、一般的な有効自由度が決まるとは扱わない。初期実装では回帰や同時観測など、推定方法と自由度が明らかな組を対象とする。由来が不明な任意の相関付き入力では、uを計算できても自由度が未評価となる場合を認める。その場合、自動方式によるk・Uを確定値として表示しない。

この情報の入力は計算元の機能で行い、作業者に内部IDや一般的な共分散ブロックの登録を要求しない。独立した回帰モデルが同じ生データや共通の校正値を使っている場合の依存関係は、別途確認が必要である。

## 同時観測を使う操作

測定表は、Type Aの評価方法から必要時に開く補助画面とする。単独の観測列だけで足りる量では、現在の入力方法を継続する。測定表を使う場合は、同じ行を同じ観測組として保持する。

作業者はCSV等の表を取り込み、列の名前と単位を確認し、必要なら派生列の式を入力する。その後、対象量に使う列を選ぶ。以下の二つの評価を明示して、計算手順の違いを保持する。

| 評価方法 | 例 |
|---|---|
| 各列を平均してモデルへ渡す | GUM H.2のV・I・位相の平均と、それらの相関 |
| 同じ行の値で式を計算してから平均する | GUM H.2の各組のR・X・Z、H.4の各サイクルの比 |

欠測・除外は観測組単位で扱い、使用した行数を表示する。列ごとに行をずらしたり、相関係数ごとに異なる行を無言で使ったりしない。並べ替えでは行全体を移動する。一定値の列など、相関を推定できない場合も0へ置換せず表示する。

最初は同時観測の一つの表と行ごとの計算までに限定する。一般的なスプレッドシートのセル参照、複数表の結合、マクロは追加しない。群別ANOVAは別の後続課題とする。

## 結果確認と包含条件

通常の結果表示は、中心値、標準不確かさ、自由度、包含条件、k、Uに絞る。包含条件は「95%・t分布」「99%・自由度切捨て」「k指定・根拠あり」のように短く要約し、詳細を既存の設定ダイアログで開く。

包含条件ダイアログでは、方法を選んだ後に必要な項目だけを表示する。自由度から計算する方法では包含確率と自由度の扱いを表示し、k指定では係数と採用根拠を表示する。係数の指定を、包含確率の検証済み表示へ置き換えない。

95%、95.45%、99%を選択例として用意し、一般の指定値も検証して受け付ける。EA表の再現とt分位点の数値計算は、採用方法として区別する。既存ファイルの包含条件は読み込み時に変更せず、方式を変更したときに保存する。

出力量間の共分散・相関は、複数の結果があるときに「結果どうしの相関…」から表示する。通常のバジェットを行列の常時表示で圧迫しない。結果・校正点・採用した入力の状態を表示し、レポートへ含めるか選べるようにする。

一次近似の点検とMCは任意実行を継続する。MCタブでは対象結果と校正点を引き継ぎ、実行ボタンを押したときに計算する。入力変更後は前の試行結果を最新と混同させず、再実行が必要な状態として表示する。計算回数・乱数条件・分布の前提を結果と一緒に保存する。

## 入力途中とエラーの扱い

編集中の式や数値に対し、入力のたびにモーダルダイアログを出さない。入力欄付近の説明と、評価時の対象を示すエラー表示を基本とする。式を解釈できない場合は、式・関数・対象量など、修正すべき箇所を示す。

回帰の削除、参照切れ、欠測などで評価できなくなった入力は、理由とともに未評価とする。古い評価値を最新結果として使わない。uは評価できても自由度が未評価の場合は、成立している部分までを表示し、k・Uが未評価であることを区別する。

レポートにも入力元、採用方法、未評価事項を反映する。画面の確認メッセージを閉じただけで計算上の問題が解決したことにはしない。

## 実装順序と受入条件

| 順序 | 実装範囲 | サンプルによる確認 | 操作面の条件 |
|---|---|---|---|
| 1 | 数学関数の解釈とエラー表示 | GUM H.2手法1のR・X・Zが計算でき、未知関数には理由を表示 | 新しい入力画面を増やさない |
| 2 | 線形回帰予測の接続と推定元の保持 | GUM H.3の補正・u・自由度9、同じ回帰の複数利用時の相関を検証 | 回帰モデルとxの選択で設定でき、係数・相関を転記しない |
| 3 | 包含確率とt分位点 | GUM H.1の99%、EA S12の95.45%。既存方式の再読込も確認 | 既存ダイアログ内で選択し、結果には条件の要約を表示 |
| 4 | 同時観測表・派生列・出力共分散 | GUM H.2・H.4の二つの手法と出力共分散 | 表の元データを一度入力し、行の対応と派生列を保持 |
| 後続 | 基本的な単位表記、MC比較の保存 | kPa・min等、EA S4の一次計算と任意MC | 無言の数値換算やMCの自動起動を行わない |

各段階で保存・再読込、点の切替、入力元の変更と取消、参照切れ、古い結果の無効化を確認する。従来の直接入力だけのモデルでも操作が増えていないことを確認する。

UIの確認では、通常のPC画面で主要入力と評価結果が読み取れること、キーボードで入力順に移動できること、補助画面から元の量・校正点へ戻れることを確認する。回帰などの詳細説明を通常フォームへ常時追加しない。

汎用的な高次伝播、分布やkの自動選択、汎用ANOVA、分野別専用画面、任意コード実行、DB・台帳・校正業務管理は、この実装範囲に含めない。
